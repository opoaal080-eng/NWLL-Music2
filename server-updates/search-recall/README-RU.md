# SoundCloud — основной источник Nightwell Music

Исправлены поиск, перенос и подборки: сначала используется SoundCloud, Audius
подключается как резерв. В поиске достаточно одного подходящего результата
SoundCloud; незавершённый поиск не считается пустым. Явный выбор источника
`provider=audius` или `provider=soundcloud` сохраняется.

«Моя волна» сначала выбирает до 20 подходящих записей SoundCloud, рекомендации —
до 60. Audius дополняет только нехватку после фильтров настроения, языка,
прослушиваний, исключённых записей и скрытых артистов. Разнообразие артистов,
избранное и оценка вкуса продолжают работать внутри основного источника.
Фоновая загрузка Audius начинается после завершения задачи SoundCloud или
ограниченного ожидания 15 секунд; общая задача SoundCloud при этом не отменяется.

## Готовые файлы для владельца сервера

1. Останови сервер и сохрани исходные версии заменяемых файлов.
2. Скопируй **все шесть файлов** из отдельного готового архива в прежнюю папку
   сервера рядом с `soundcloud_import.py`:
   `app.py`, `nightwell_search_recall.py`, `full_version_search.py`,
   `adaptive_wave.py`, `wave_ranker.py`, `audius_catalog.py`.
3. Запусти сервер прежним способом и повтори поиск и «Мою волну».

Готовый `app.py` сделан из присланного владельцем файла и сохраняет его
остальные настройки. Полный файл не публикуется в GitHub. Его нельзя брать
из публичного репозитория вместо личного архива. Остальные серверные модули,
базы и настройки заменять не нужно.

Изменение IPA само по себе не обновляет сервер на компьютере. Подборки в этой
версии сервера обслуживаются модулем `adaptive_wave.py`, а дополнительная
обёртка поиска — `audius_catalog.py`; поэтому обновление включает оба модуля.

## Установка патчем из исходного пакета

Установщик проверяет совместимость до записи файлов. Из папки
`server-updates/search-recall` в полной копии репозитория:

```bat
py -3 search_recall_install.py --target "C:\Nightwell Music\nightwell-music" --check
```

Останови сервер и выполни ту же команду без `--check`, затем перезапусти его.
Создаётся `backups/nw-search-recall-…`. Для отката:

```bat
py -3 search_recall_install.py --rollback "C:\Nightwell Music\nightwell-music\backups\nw-search-recall-ДАТА"
```

Поддерживается обновление проверенной предыдущей версии патча поиска.
Неизвестный код обработчиков или модулей останавливает установку до изменений.
Повторная установка не меняет уже обновлённые файлы; BOM/CRLF сохраняются.

## Проверки

```bat
py -3 -m unittest discover -s server-updates/search-recall -p "test_*.py" -v
py -3 -m unittest discover -s server-updates/adaptive-wave -p "test_*.py" -v
py -3 -m unittest discover -s server-updates/audius -p "test_*.py" -v
```

Проверяются настоящий обработчик из очищенной fixture, действующий модуль
подборок с SQLite, очередь фонового поиска и поздняя обёртка Audius.
Сетевые провайдеры заменены имитациями; наличие конкретной записи на компьютере
владельца зависит от текущего ответа SoundCloud и его настроенного доступа.
