# Ограничение ожидания выбора качества

Этот модуль дополняет существующий FastAPI-сервер. Он использует только официальные доступные AAC HLS-варианты SoundCloud и сохраняет обычный `/api/stream` как fallback. Цены, Premium и разрешения на офлайн не меняются.

Исправления задержек:

- Проверка доступного трека в каталоге ограничена общим дедлайном 2,5 секунды, даже если внутренний ASGI-обработчик не отвечает.
- Вся цепочка токен → разрешение записи → потоки ограничена 4 секундами суммарно. Нельзя сложить несколько отдельных сетевых таймаутов в минуты ожидания.
- Одновременные запросы options/stream и разных качеств одного трека объединяют обращение к источнику; отмена одного клиента не отменяет задачу остальных.
- Неудачное определение вариантов даёт короткую паузу 2 секунды перед повтором. Успешный выбор кешируется на 45 секунд, как раньше, но доступ к треку проверяется заново до использования кешированного адреса.
- Только внутри того же приложения передаются cookie, Authorization, CSRF и ключ устройства. Идентичность аккаунта по-прежнему проверяет действующий сервер.

Дедлайны ограничивают дополнительный этап выбора качества, а не гарантируют старт аудио: после fallback обычный серверный `/api/stream` может иметь собственную задержку. Его production-кода здесь нет. Для установки обновите `audio_quality.py` рядом с действующим сервером, сохранив существующий вызов `install(...)` и настройки; если модуль ещё не подключён, нужна явная интеграция с актуальным `app.py`. Не заменяйте основной сервер этим файлом.

Проверки: `python -m unittest discover -s server-updates/audio-quality -p "test_*.py" -v` из корня репозитория. Все обращения в тестах замоканы; реальные источники и секреты не нужны.
