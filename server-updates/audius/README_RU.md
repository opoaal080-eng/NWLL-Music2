# Audius для Nightwell Music

Обновление музыкального сервера от 7 ноября 2026 года.

## Установка

1. Распакуй весь архив в отдельную папку.
2. Останови музыкальный сервер его обычным способом.
3. Запусти `Install_Audius.bat`. По умолчанию он найдёт сервер в `C:\Nightwell Music\nightwell-music`.
4. После сообщения об успешной установке запусти сервер привычным батником.
5. Повтори поиск или создай новый перенос плейлиста. В «Твоём ритме» нажми «Новая подборка».

Если сервер лежит в другой папке, передай её первым аргументом:

```bat
Install_Audius.bat "D:\Nightwell Music\nightwell-music"
```

Установщик добавляет Audius, обновляет модуль подборки v3 и сохраняет резервную копию изменённых файлов. Не заменяет весь сервер, настройки переноса, аккаунты, плейлисты, подписки, конфигурацию или интерфейс. Работает как с установленной Adaptive Wave v3, так и без неё. Если обнаружена неизвестная изменённая версия модуля подборки, установка останавливается до записи файлов.

Новые EXE, APK и IPA для этого изменения не нужны. Используется общий серверный каталог и прежние маршруты клиентов.

## Что добавлено

- Общий поиск одновременно проверяет Audius и прежний источник. Повторные запросы используют кэш, долгий поиск возвращает обычный статус ожидания.
- Перенос Яндекс/Spotify/ВК и текстовых списков получает результаты Audius через тот же поиск. Сверка названия, исполнителя и длительности остаётся в действующем модуле переноса.
- «Твой ритм» ищет музыку в Audius по персональным запросам и жанрам собственной истории. Результаты проходят общий отбор v3 с учётом лайков, ранних пропусков, скрытых треков, настроек и повторов. Дубли одной записи из разных источников не попадают в одну порцию.
- Поиск для подборки выполняется в фоне. Он не задерживает уже готовые треки. Новые находки становятся доступны в следующих порциях. В режиме «Избранное» внешний поиск не запускается.
- Воспроизведение через сервер, перемотка с Range, HEAD, обложки и сохранение треков в плейлистах. Загрузка через существующий офлайн-экспорт доступна только для треков с разрешённым скачиванием и при выполнении прежних условий Nightwell.
- Перед воспроизведением проверяется актуальная доступность трека. Закрытые, платные, удалённые и ограниченные ключом треки не выдаются как полный открытый поток.

Сбой Audius не отключает другой источник. Audius дополняет каталог, но наличие конкретной песни и точного оригинала зависит от доступных загрузок. Уже завершённый перенос сам не пересобирается: повтори его для поиска пропущенных песен.

## Проверка

После входа в Nightwell открой `/api/audius/status` на своём музыкальном сервере. Ожидаются `version: audius-1.0`, `search: true`, `playlist_import: true`, `wave: true`.

Установка без записи:

```bat
python install_audius.py --target "C:\Nightwell Music\nightwell-music" --check
```

Откат после остановки сервера:

```bat
python install_audius.py --rollback "C:\Nightwell Music\nightwell-music\backups\audius-ДАТА-ВРЕМЯ"
```

Точный путь резервной копии выводится при установке. Откат не перезаписывает файлы, которые менялись после этого обновления. Каталог найденных треков остаётся в базе. После отката модуля Audius эти записи не смогут воспроизводиться до повторной установки.

## Технические сведения

Используется [официальный Audius API](https://docs.audius.co/api/), поиск `/v1/tracks/search`, метаданные `/v1/tracks/{id}` и поток `/v1/tracks/{id}/stream`. Аудио не перекодируется при онлайн-воспроизведении. Внешним узлам не передаются cookie или данные аккаунта Nightwell. Редиректы проверяются перед подключением.

Публичные чтения работают без ключа. При необходимости свой API-ключ можно задать на сервере переменной `NW_AUDIUS_API_KEY` перед запуском. Не вставляй ключ в клиентские приложения. Ошибки ограничения частоты обрабатываются паузой повторных запросов.

Нужны имеющиеся у сервера FastAPI и httpx, Python 3.10+. Прямой серверный DNS должен разрешать публичные медиаузлы Audius. Дополнительные зависимости для нового источника не устанавливаются автоматически.

Тесты: `python -m pytest server-updates/audius/tests server-updates/adaptive-wave/tests server-updates/playlist-transfer/test_transfer.py`.
Проверка живого API, одного диапазона MP3 и обложки: `python smoke_live.py` из папки обновления.
