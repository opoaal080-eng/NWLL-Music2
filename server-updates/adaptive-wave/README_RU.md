# Nightwell Music: адаптивная подборка v3

Обновление серверной подборки для Windows, iPhone, Android и веб-клиента.
Использует существующие лайки, плейлисты, прослушивания, пропуски и выбранных артистов.

## Установка

1. Распакуй весь архив в отдельную папку.
2. Запусти `Install_Adaptive_Wave.bat`. По умолчанию сервер ищется в `C:\Nightwell Music\nightwell-music`.
3. Перезапусти музыкальный сервер своим обычным батником.
4. В приложении нажми **«Новая подборка»**, чтобы заменить ранее собранную очередь.

Если сервер находится в другой папке, передай её первым аргументом батнику или выполни:

```powershell
python install_adaptive_wave.py --target "D:\Nightwell Music\nightwell-music"
```

## Что меняется

- Длинная история задаёт общий вкус, а последние 45 минут помогают подстроиться к текущему прослушиванию.
- Лайки, сохранённые песни и выбранные артисты дают положительные сигналы с ограниченным весом. Один старый исполнитель не занимает всю очередь.
- Ранний пропуск после нескольких секунд снижает интерес к записи. Ошибка старта или случайное мгновенное переключение не считаются музыкальным дизлайком.
- Почти полностью прослушанный трек считается положительным сигналом, даже если затем нажата кнопка «Далее».
- Два ранних пропуска за неделю временно исключают запись на 48 часов. Один такой пропуск убирает её из текущей сессии на 30 минут.
- Одна песня из разных источников и типовые повторные загрузки объединяются при отборе.
- При наличии вариантов один исполнитель не повторяется среди трёх предыдущих песен.
- При наличии вариантов каждое четвёртое место отводится незнакомой записи, предпочтительно близкой по исполнителям, жанровым метаданным или вкусам похожих слушателей.
- «Открытия» исключают уже прослушанные и сохранённые записи, включая дубли. «Избранное» остаётся в пределах лайков.
- Жанр, настроение и язык учитываются по имеющимся метаданным. Анализ звучания аудио эта версия не выполняет.
- Новые порции предпочитают ещё не предложенные треки. При небольшом каталоге после исчерпания вариантов возможен возврат к более старым предложениям.

Основное изменение относительно прежней схемы: все три адреса `/api/wave`, `/api/recommendations` и `/api/wave-artists/mix` используют один отбор. Дополнительный поиск артистов больше не подмешивает треки в обход фильтров.

## Быстродействие и совместимость

SQLite и ранжирование выполняются в рабочем потоке. Пополнение каталога запускается через уже существующую фоновую загрузку и не задерживает выдачу готовой подборки. Новых внешних сервисов или платных API не требуется.

Установщик добавляет два модуля и короткое подключение в действующий `app.py`. Исходники текущего сервера, платёжные и музыкальные данные не заменяются полным архивом старой версии. Перед заменой создаётся резервная копия изменяемых файлов.

В архиве нет баз данных, пользовательских сессий, настроек прокси, музыки или кеша.

Проверка без записи:

```powershell
python install_adaptive_wave.py --check --target "C:\Nightwell Music\nightwell-music"
```

Откат файлов по выведенной установщиком папке:

```powershell
python install_adaptive_wave.py --rollback "C:\Nightwell Music\nightwell-music\backups\adaptive-wave-..."
```

Проверка установленной версии: авторизованный запрос к `/api/recommendations/status` возвращает `adaptive-wave-3.0`.

## Проверено

Проверены обработка сигналов, повторов, режимов, артистов, языковых фильтров, разделение аккаунтов, конкурентные запросы, сохранение текущей авторизации и отзыва публикации, установка и откат. Установщик также проверен на предоставленном `app(8).py`.

Качество ранжирования на реальной истории конкретного аккаунта нужно оценить после установки. Эта версия не использует закрытые модели или данные Яндекс Музыки.
