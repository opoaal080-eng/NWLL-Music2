# Проверка восстановления приложений, 21.10.2026

## Исправлено
- В Android GitHub Actions путь к `scripts/validate-app-sources.py` теперь учитывает `working-directory: android`. Предыдущий путь приводил к ошибке `file not found` до компиляции.
- Установка SDK больше не подаёт `yes` в `sdkmanager`: ненужный поток мог прерывать шаг с `pipefail`.

## Проверки
- XML/XAML и Swift parser: повторная проверка локально.
- Выполняемая сборка IPA / APK / EXE **не подтверждена**. Среда не содержит Android SDK, Xcode и Windows .NET WPF SDK.
- Наличие CI workflow **не равно** успешной сборке.

## Важные ограничения
- Android исходники всё ещё версии 1.1.6-autumn, Windows 1.1.1. Наименование текущих установленных сборок 1.2.0 не означает, что код соответствует им.
- Отсутствует гарантия идентичности с последним установленным iOS приложением.
- Сборки Android с веб-оплатой могут быть несовместимы с требованиями Play Store.

## Запуск сборок
Загрузить папки из ZIP в выделенный GitHub репозиторий с сохранением структуры, затем запустить три workflow во вкладке Actions. Сохранить SHA коммита и логи каждой сборки.
