# Nightwell Music: проверка CI и соответствия сборок (21 октября 2026)

- Локальные проверки: Swift parser, iOS source guard, Android XML и Windows XAML прошли.
- Проверены workflow Android, iOS и Windows. В каждую сборку добавлена запись SHA-256, размера и SHA коммита, чтобы идентифицировать полученный установочный файл.
- `build-provenance.py` возвращает ошибку, если выходной APK/IPA/EXE отсутствует. Это не позволяет ошибочно назвать сборку успешной без артефакта.
- Сборки IPA/APK/EXE в этой среде **не выполнены**: macOS Xcode, Android SDK и Windows WPF SDK отсутствуют.
- Последние установленные приложения могут отличаться по функциям: iOS MARKETING_VERSION 1.0.3, Android 1.1.6-autumn, Windows 1.1.1. Нельзя менять номера на 1.2.0 без подтверждения кода.
- Android debug-сборка использует debug-ключ. Чтобы обновлять текущую установленную версию без удаления данных, нужен **тот же самый ключ подписи**, что и у предыдущей установки. Сохранённый ключ отсутствует в этом архиве.
- На GitHub не загружались новые файлы. Текущая версия проекта готова к загрузке в репозиторий, но не прошла облачную сборку.
