# Nightwell Music — восстановление приложений

Этот репозиторий содержит исходники клиентов **iOS, Android и Windows**, а также отдельные серверные дополнения. Полного основного Python/Go-сервера здесь нет.

## Где находятся рабочие исходники

- **iOS:** `NightwellMusic/` и `project.yml`. Xcode собирает из `NightwellMusic/`.
- **Android:** `android/app/src/main/java/fun/nightwell/music/`.
- **Windows:** `windows/`.
- **Серверные дополнения:** `server/` и `server-updates/`, они не заменяют основной сервер.
- **`source/`: архив восстановленных исходников, не рабочая Android/Windows-ветка. Некоторые Swift-копии здесь старее действующих файлов. Не заменяйте актуальный код архивом без сравнения. `MusicStore.swift` синхронизируется с зеркалом при обновлениях.

При переносе изменений запускайте CI сборки нужной платформы.

Исходный архив: `Nightwell-Music-Apps-CI-Audited-20261021.zip` (21.10.2026). Точные совпадения с последними сборками пока не подтверждены.

⚠️ Перед публичной загрузкой проверьте файлы на токены, ключи и приватные данные.
