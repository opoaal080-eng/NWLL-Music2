# Nightwell Music — нативная тестовая версия

Ветка `feat/native-ui`, отдельный черновик PR. Основная ветка и работающий сервер не заменены.

- iOS: SwiftUI, AVPlayer, системные команды MediaPlayer; HTML/JavaScript и WebKit отсутствуют в проекте.
- Android: системные View/ListView, Canvas, существующая Media3-служба; ресурсы веб-клиента и зависимости android.webkit удалены.
- Windows: WPF/.NET 8 и LibVLC, без Electron и WebView2. Установщик ставит тестовый клиент рядом с прежним.

Реализованы API-вход/регистрация, каталог и поиск, избранное, плейлисты, офлайн-аудиофайлы, массовое скачивание, ссылки на Nightwell, управление очередью, переходы громкости. iOS и Android показывают синхронизированные строки, если сервер возвращает таймкоды. Windows также дожидается окончания поиска и показывает текущую строку по таймкодам.

Поиск выполняется вне потока интерфейса. Устаревшие запросы отменяются или их результаты отбрасываются. Списки используют создание/переиспользование видимых строк. Ленты рисуются отдельно нативным Canvas с ограниченной частотой кадров и останавливаются, когда экран скрыт. В iOS обновление позиции плеера не вызывает обновление всех строк списка.

Это первая тестовая миграция, не окончательная замена стабильной версии. В этой итерации добавлены восстановление очереди и позиции на паузе, свайпы iOS/Android, заставка и туман iOS, реакция лент на доступный PCM-уровень iOS/Android, фоновая очередь скачивания (iOS URLSession / Android foreground preparation + DownloadManager), повторные запросы до завершения поиска текстов и исключение текущих/недавно сыгранных треков из новой подборки. Расширенные эффекты Windows и автоматический перенос офлайн-кэша из Electron в WPF ещё не перенесены полностью. Файлы прежних приложений не удаляются. В Android и iOS используются прежние папки офлайн-хранилища. Повторный вход может потребоваться.

Проверки: CI собирает симулятор и устройство iOS, запускает SwiftUI-экран в симуляторе, собирает APK и выполняет Android lint, собирает WPF и запускает его для получения контрольного снимка. Android-эмулятор проверяет отсутствие WebView в иерархии интерфейса. Полное воспроизведение с личным аккаунтом и быстродействие на реальных устройствах этим не проверяются.

Сборка: iOS — XcodeGen и project.yml на macOS; Android — Gradle 8.11.1, Java 17, SDK 35; Windows — dotnet publish windows/Nightwell.Native.csproj -c Release -r win-x64 --self-contained true. Готовые пакеты собираются в GitHub Actions. IPA без подписи, требует подписи перед установкой. Windows-пакет включает .NET и библиотеки LibVLC.

Сайт остаётся веб-сайтом. Серверный API не требует переписывания под нативные клиенты. Полный сервер с веб-интерфейсом поставляется отдельно.

Фоновая загрузка iOS продолжается при сворачивании/блокировке. Принудительное закрытие приложения пользователем отменяет системные передачи: сохранённая очередь восстанавливается при следующем запуске. Android использует системную очередь с уведомлениями и повтором при восстановлении сети. Сетевые ошибки не сохраняются как успешный офлайн-файл.

1.0.2 iOS: текст с таймкодами отображается в главной сцене и в режиме «Только фон»; настройка включена при первом запуске. Учитывается ранее выбранное отключение. Цвета лент iOS, Android, Windows и сайта приглушены. Серверная добавка в server-addon/native-offline-wait.patch ускоряет системные загрузки; полный сервер поставляется отдельным архивом.
