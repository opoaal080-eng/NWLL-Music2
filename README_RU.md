# Nightwell Music, восстановление графики iOS

Оригинальная IPA (сборка 354) и новая восстановленная IPA имеют разные исполняемые файлы. Этот пакет сохраняет исполняемый файл новой сборки и заменяет лишь скомпилированные графические ресурсы `Assets.car` и две иконки из сборки 354.

`Nightwell-Music-recovered-original-assets-unsigned.ipa` — собранная неподписанная IPA с заменёнными ресурсами. Это экспериментальная версия. Её отображение и работа не проверялись на iPhone. Возможна несовместимость названий ресурсов и кода.

`source/` содержит исходники восстановленного проекта, а `ios/LegacyCompiledAssets/` — старые компилированные ресурсы для включения в приложение после сборки. Это НЕ редактируемые исходники изображений. Скрипт `ios/apply_legacy_assets.py` заменяет их после `xcodebuild` и до упаковки IPA. GitHub Actions сборки iOS в `source/.github/workflows/build-ios.yml` дополнен этим шагом.

Не коммитьте приватные данные или ключи подписи. Оригинальный файл IPA не изменён. Никакие серверные файлы не добавлены.
